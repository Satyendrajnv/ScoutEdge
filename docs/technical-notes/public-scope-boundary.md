# Public Scope & Intellectual Property Boundary

This technical note defines the strict engineering scope boundary between open public components and proprietary enterprise software at ScoutEdge.

---

## Public Scope (Open Architecture & Reference Implementations)

The components published in this open architecture repository serve to establish:
- **Contract Specifications**: Data schemas for Athlete, Signal, Rating, and Decision objects.
- **Reference Scoring Engines**: Baseline math for standardized rating formulas, ACWR workload calculations, and growth progression algorithms.
- **Pipeline Abstractions**: Extensible Python interfaces for building sports intelligence tools.
- **System Documentation**: Architecture diagrams, ADRs, and technical governance specifications.

---

## Proprietary Scope (Internal Enterprise Infrastructure)

The following assets are strictly internal to EdgeSphere Sports Intelligence Private Limited:
- **Trained AI/ML Models**: Neural networks, computer vision pose estimation models, and proprietary model weights.
- **Private Data Registries**: Proprietary scouting databases, partner sports organization data, and PII-protected athlete tracking data.
- **Enterprise API Keys & Secrets**: Infrastructure connection strings, deployment secrets, and production keys.
- **Patent-Sensitive Algorithms**: Proprietary predictive modeling algorithms and proprietary vision intelligence mechanics.
